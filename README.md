# MEMORY BEAT

問題と答えを自由に登録し、落下ゲーム・4択回答・BGMで反復する汎用暗記PWA。TOEIC BEATを参考にした独立アプリです。

## 使う
初回またはv1.1.0への更新時に「TOEIC英単語」500語が追加されます。START → 日本語の意味を4択からタップ。
ゲームを作成 → 問題と答えを追加（タブ区切り一括追加も可）でも利用できます。選択肢は個別指定または同じゲームの答えから作成します。
教材は導入時に一度だけ追加し、既存問題・履歴を上書きしません。教材を削除しても次回起動で勝手に再追加しません。

- ゲーム数は固定なし。ゲームごとの問題管理・成績・履歴。
- EASY 6秒 / NORMAL 4.5秒 / HARD 3秒 / EXPERT 2秒。問題数または時間でプレイ。
- 標準は選択式・マイクOFF。回答方法を切り替えると音声・手動・文字でも学習可能。
- 日本語/英語の端末内読み上げ、別解、誤認識の正解修正。
- PERFECT/GREAT/GOOD/MISS、コンボ、粒子・リング演出、内蔵BGM3曲、自分の音楽。
- v1.2.0では「小春リアクション」試作を追加。正解評価とコンボに連動して表情・応援メッセージ・強い衝撃演出が変化し、10コンボ以上でKOHARU FEVERへ移行します。現在の小春表示は画像差し替え前のUIデモで、実画像を追加しても学習データ構造は変わりません。
- 未学習・苦手・遅い回答・最近のミス・長期未出題を優先。
- 日別推移、前回比pt、ゲーム別/総合成績、snapshot付き履歴。
- 問題の一括選択、移動、コピー、無効化、削除、並び替え。ゲーム名/色/アイコン編集。
- 完全JSONバックアップ・検証付き復元、AI編集用出力。
- IndexedDB、永続保存申請、PWA・オフライン、noindex。

## プライバシー
実際の人名・会社・部署の問題は端末内IndexedDBに登録します。リポジトリはアプリ本体・公開可能な英語教材・架空のテストだけです。分析SDK、外部AI API、暗記情報の自動アップロードはありません。

初期設定は選択式・音声認識OFFです。音声回答を使う場合は端末内認識を選択でき、非対応なら手動判定にします。通常認識は使用前に明示同意が必要です。端末内の日本語認識は実験的で、端末とブラウザーに依存します。TTSも指定言語の端末内音声がない場合は文字出題になります。

同じGitHub Pagesオリジンのアプリ間ではブラウザーの保存領域を共有します。DB名とキャッシュは他アプリと分離していますが、オリジン内で動く別のコードに対するアクセス制御にはなりません。機密情報の運用は会社の方針に従ってください。
ブラウザーのデータ削除・端末変更に備えてバックアップを保存してください。音楽Blobはバックアップに含めません。AI用出力も利用者が確認してファイルを共有する方式です。

## GitHub Pages公開
リポジトリ名：`memory-beat`。Settings → Pages → Deploy from a branch → **main / (root)** → Save。
ビルド工程は不要。`index.html`、`js/`、`icons/` をこの階層へ置きます。ZIPの外側フォルダーごとではなく、中身をリポジトリのルートへ置いてください。

PWAのidは `/memory-beat/`、scopeも同じ範囲です。別リポジトリへ移植する場合は専用パスへ変更してください。`id: "./"` はoriginのルートへ解決され、別アプリと識別子が衝突するため使いません。旧版が残る場合は [データを保持して更新](https://yuuuh26.github.io/memory-beat/update.html) を開いてください。

教材の原本：[yuuuh26/toeic-beat](https://github.com/yuuuh26/toeic-beat) の500語と例文補正。元のリポジトリは変更していません。導入データと参照commitは `data/toeic.json` に記録しています。
